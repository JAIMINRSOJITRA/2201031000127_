# Travelling App — UI Design

A UI/UX design assignment: a travel app concept designed in Figma, exported as a static HTML/CSS prototype.

## Contents

- `assigment_1` — link to the Figma design file
- `Travelling App (Community).zip` — the Figma design exported to code (24 static screens) via Anima, bundled with Parcel
- `Screenshot 2024-02-24 234734.png` — preview screenshot

## Previewing the exported prototype

```bash
unzip "Travelling App (Community).zip"
cd "Travelling App (Community)"
npm install
npm start
```

This opens the exported screens in your browser via Parcel's dev server.
